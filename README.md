# Projeto_Pokedex
🗺️ PokéDex - Visão de Projeto

Uma aplicação web interativa voltada para o mundo Pokémon, desenvolvida como projeto acadêmico para listagem, busca e gerenciamento de coleções personalizadas dos Pokémons.

🎯 Sobre o Projeto
O objetivo deste projeto é construir uma PokéDex moderna que consome dados reais e completos da PokéAPI. A aplicação permite aos usuários explorar o ecossistema Pokémon, salvar seus favoritos em uma coleção persistente no navegador e alternar a identidade visual do sistema através de um tema customizável. 

O projeto ainda está em andamento!
