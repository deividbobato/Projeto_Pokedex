# Pokédex — tela de entrada

Recriação da tela de referência usando somente HTML e CSS.

No ZIP, abra `index.html` no navegador após extrair todos os arquivos. No repositório, a página fica em `dist/index.html`. Não precisa instalar programas, executar comandos ou ter conexão com a internet.

- `dist/index.html`: estrutura da página e campos do formulário.
- `dist/style.css`: cores, espaçamentos, posição dos elementos e versão para celular.
- `dist/assets/`: imagens e fontes usadas na página.

A página é uma interface visual. Os campos podem ser preenchidos, mas o botão Entrar não envia nem armazena dados. Os links de cadastro e recuperação ficam como pontos de ligação para futuras páginas. O botão de ajuda abre uma explicação usando o elemento HTML `details`.

O cenário foi recriado a partir da imagem fornecida, com retirada dos elementos de interface. Por isso, a paisagem pode apresentar pequenas diferenças em relação à referência.

## Créditos dos recursos

- Cenário: recriado a partir da referência enviada pelo usuário.
- Logotipo Pokémon: https://commons.wikimedia.org/wiki/File:International_Pok%C3%A9mon_logo.svg
- Fontes: Press Start 2P, Poppins e Pixelify Sans, disponíveis no Google Fonts. Licenças incluídas em `assets/`.
